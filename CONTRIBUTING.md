# Contributing

Bug reports: include the machine and the device IDs involved, the macOS version and build (`sw_vers`), the OpenCore version, the version of the kext or driver, and the logs the repo's README names. Most repos list the exact `log show` / `ioreg` command to run.

Reports from other hardware are very welcome, working or not.

Pull requests: small, one change each, and say how you tested it. I read and test every PR before merging. AI-assisted PRs are fine as long as you can explain the change, the same bar I hold my own code to.
